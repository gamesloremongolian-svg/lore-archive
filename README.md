# Lore Archive

**The Unified Lore Encyclopedia** — тоглоом, анимэ, манга, Light Novel, Web Novel болон тэдгээрийн зохиомол ертөнцийн мэдлэгийг олон хэлээр цуглуулах нэгдсэн архив.

## Хөгжүүлэлтийн үндсэн төлөвлөгөө

Нэгдсэн платформын зорилго, хөгжүүлэлтийн үе шат, шалгуур болон төлбөрийн хамрах хүрээг [`docs/MASTER_ROADMAP.md`](docs/MASTER_ROADMAP.md)-ээс үзнэ үү. Шууд QPay → LORE Coins цэнэглэлт төлөвлөгөөнд ороогүй.

## Архивын ангилал

- **Game Lore** — тоглоомын ертөнц, дүр, байршил, фракц, зүйлс, үйл явдал
- **Anime** — цуврал, улирал, анги, дүр, үйл явдал
- **Manga** — цуврал, бүлэг, дүр, зохиолын хувилбар
- **Light Novel / Web Novel** — боть, бүлэг, дүр, үйл явдал
- **Universe Archive** — франчайз, бүтээл, дүрүүдийн холбоо, цаг хугацааны шугам

Эхний ээлжид Genshin Impact, Wuthering Waves, ANANTA, Honkai: Star Rail, Zenless Zone Zero, Arknights, Blue Archive зэрэг тоглоомын ертөнцийг хамруулах бүтэцтэй. Шинэ франчайз, бүтээл нэмэх боломжтой.

## Хэрэгжсэн боломжууд

- Нэгдсэн нүүр хуудас, ангиллын навигаци болон каталогийн хайлт.
- Анимэ, манга, Light Novel, Web Novel-ийн мета өгөгдлийн хайлт — AniList GraphQL.
- Тоглоомын lore нийтлэлийн хайлт — Supabase дахь нийтлэгдсэн контент.
- Нэгдсэн архивын өгөгдлийн сан: Franchise, Work, олон хэлний Work Translation, Entity, Entity Translation, Entity Relation, Timeline Event, Timeline Translation.
- Олон хэлний редакцын CMS: `/editorial/`.
- CMS-ээр франчайз, бүтээл, орчуулга, дүр/байршил/фракц/зүйл/ойлголт, тэдгээрийн холбоо, цаг хугацааны үйл явдал болон орчуулгыг удирдах.
- Нийтийн архивт зөвхөн нийтлэх төлөвт орсон бичлэг, орчуулгыг харуулах.
- Монгол (mn), English (en), 日本語 (ja), 한국어 (ko) хэлний сонголт.
- Одоогийн community болон хэрэглэгчийн функцуудыг хадгалсан.

## Өгөгдөл ба редакцын стандарт

Боломжтой тохиолдолд бичлэг бүрд албан ёсны эсвэл анхдагч эх сурвалж, canon төлөв, spoiler түвшин, хэл, редакцын төлөв, орчуулгын мэдээллийг тэмдэглэнэ. Онолыг баталгаатай баримтаас тусад нь ялгана.

AI-аар үүсгэсэн ноорог, орчуулгыг редакторын хяналтгүйгээр баталгаатай баримт гэж нийтлэхгүй. Зохиогчийн эрхээр хамгаалагдсан бүтээлийг зөвшөөрөлгүйгээр бүтнээр нь хуулбарлахгүй.

## Одоогийн хязгаарлалт ба дараагийн шат

- AniList-ийн media format/source ангилал бүрэн төгс биш тул Light Novel болон Web Novel-ийн ангилал зарим бүтээл дээр алдаатай байж болно.
- Тоглоомын хайлт нь одоогоор Lore Archive-д нийтлэгдсэн контентоор хязгаарлагдана; бүх тоглоомын гаднын бүрэн каталог биш.
- CMS-д редакцын батлах тусгай queue, өөрчлөлтийн хувилбарын түүх, media upload, audit log болон илүү нарийн эрхийн түвшинг цаашид хөгжүүлэх шаардлагатай.
- Бодит хэрэглэгчийн эрхээр CMS хадгалалт болон GitHub Pages-ийн production deployment-ийг тусад нь шалгах шаардлагатай. Статик кодын шалгалт нь live deployment амжилттай гэсэн баталгаа биш.

## Технологи ба аюулгүй байдал

Веб нь статик HTML/CSS/JavaScript, Supabase болон AniList-ийн нийтийн API ашиглана. Browser-д зөвхөн Supabase publishable key ашиглана. `service_role` болон secret key-г frontend кодод хэзээ ч байрлуулахгүй.

Өгөгдлийн хамгаалалт нь RLS policy болон сервер талын эрхийн шалгалтад тулгуурлана. Нийтийн хэрэглэгч зөвхөн нийтлэгдсэн архивын мэдээллийг унших ёстой; редакцын үйлдэл идэвхтэй staff эрхээр хязгаарлагдана.

## Хөгжүүлэлт ба байршуулалт

- Үндсэн салбар: `main`
- Статик шалгалт: `python scripts/check_site.py`
- GitHub Actions нь Pull Request болон `main` салбарын push бүрд smoke check ажиллуулахаар тохируулагдсан.
- GitHub Pages-ийн бодит deployment төлөвийг Repository → Settings → Pages болон Actions дээр шалгана.

## AI Editorial Workspace

- Админ самбараас `/editorial/ai.html` хаягаар AI редактор нээнэ.
- Идэвхтэй `owner`, `admin`, `editor` эрхтэй хэрэглэгч л ноорог үүсгэж, хадгална.
- AI ноорог нь `ai_editorial_drafts` хүснэгтэд хадгалагдаж, редактор хяналтад илгээнэ.
- Зөвхөн `owner` болон `admin` эрхтэй хэрэглэгч хяналтад байгаа нооргийг `content_posts` руу нийтэлнэ.
- AI функц: Supabase Edge Function `editorial-ai-draft`; OpenAI түлхүүрийг зөвхөн серверийн secret-д хадгална.
- AI үүсгэсэн агуулга эх сурвалжийг автоматаар баталгаажуулахгүй. Редактор URL, canon төлөв, баримтыг нийтлэхээс өмнө шалгана.
