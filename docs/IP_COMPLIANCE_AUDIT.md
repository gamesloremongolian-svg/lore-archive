## Нээлттэй эрсдэл — AniList API

Одоогийн код AniList GraphQL API-аас анимэ/манганы мэдээлэл, постерын URL-уудыг хэрэглэгчийн хайлт, каталогийн хэсэгт ашигладаг.

AniList-ийн албан ёсны нөхцөл:
https://docs.anilist.co/guide/terms-of-use

Нөхцөлд:
- API-г backup эсвэл өгөгдөл хадгалах үйлчилгээ болгон ашиглахыг хориглосон.
- Их хэмжээний өгөгдөл бөөнөөр цуглуулахыг хориглосон.
- AniList-тэй ижил шинж чанартай, өрсөлдөх, нэмэлт бус үйлчилгээний хэрэглээг хязгаарласан.
- Сард 150 ам.доллараас дээш орлоготой үйлчилгээ commercial license авах шаардлагатай гэж заасан.

LOREVERSE нь анимэ/манганы discovery болон lore архивтай тул API ашиглалтын зөвшөөрөгдөх хүрээ тодорхойгүй. Энэ нь шууд зөрчил тогтоосон гэсэн үг биш. Гэхдээ API-г цаашид ашиглахаас өмнө AniList-ээс бичгээр тайлбар/зөвшөөрөл авах шаардлагатай. Хариу иртэл их хэмжээний өгөгдөл татах, өөрийн сан руу хуулж хадгалах, API өгөгдлөөр байнгын каталог бүрдүүлэхгүй.

## Үлдсэн шалгах зүйл

1. Бусад бүх хуудсанд байгаа гадаад зураг, видео, аудио, icon, font бүрийн эх сурвалж ба лицензийг баримтжуулах.
2. Admin/CMS-ээр хэрэглэгч зураг upload хийхэд эрх эзэмшдэг эсэх, лицензийн төрөл, эх сурвалж, credit талбарыг бүртгэх.
3. Хэрэглэгчийн пост, чат, профайл зурагт гомдол гаргах/шалгах/түр нуух/устгах ажиллагааг сервер талд баталгаажуулах.
4. GitHub repository дахь бүх asset-д лицензийн бүртгэл (asset register) үүсгэх.
5. Premium болон сурталчилгаа идэвхжихээс өмнө API, зураг, фонт, гуравдагч талын үйлчилгээний арилжааны нөхцөлийг тус бүр шалгах.
6. Монгол Улсын оюуны өмчийн хуульчаар үйлчилгээний нөхцөл болон гомдол шийдвэрлэх журмыг хянуулах.

## Нийтлэх стандарт

- Өөрийн үгээр бичсэн тайлбар, судалгаа, шүүмж, анализыг түлхүү ашиглах.
- Шаардлагатай тохиолдолд ишлэлийг богино, эх сурвалжтай, хуульд нийцүүлэн ашиглах.
- Эх сурвалж дурдсан нь зөвшөөрөлтэй гэсэн үг биш.
- Албан ёсны сайт руу холбоос өгөх нь тухайн бүтээлийг хуулбарлан байршуулснаас эрсдэл багатай.
- Зөвшөөрөл, лиценз тодорхойгүй зураг/видео/дуу/фонт байршуулж болохгүй.
- Бусдын бүтэн анги, кино, манганы бүлэг, тоглоомын asset-ийг хуулбарлан байршуулахгүй.
- Нийтлэл бүрд баримт, таамаг, фэн онолыг ялгаж, эх сурвалж ба огноог тэмдэглэх.

## 2026-11-18 нэмэлт кодын шалгалт

Нүүр хуудасны одоогийн кодоос дараах нэмэлт хэрэглээг баталгаажуулав:
- Анимэ киноны rail нь AniList GraphQL-ээр нэг хүсэлтэд 30 хүртэлх MOVIE үр дүн авч, `coverImage` URL-ийг шууд харуулдаг.
- Манганы хайлт болон нэгдсэн каталог мөн AniList GraphQL-ийг ашиглаж байна. Иймээс зөвхөн киноны rail бус, нийт AniList интеграцыг нэг бүрчлэн зөвшөөрөл/нөхцөлтэй тулгах шаардлагатай.
- Тоглоомын нийтлэлийн body доторх `cover_url`, `image_url`, `thumbnail_url`, `banner_url` талбаруудын HTTPS URL-ийг зураг болгон харуулж болно. HTTPS нь эрхийн баталгаа биш.
- Зар сурталчилгааны хүсэлтэд `image_url` болон `target_url` талбарууд байна. Зар оруулагч өөрийн зураг болон линк ашиглах эрхтэй гэдгийг баталгаажуулах шаардлагатай.
- Үйлчилгээний нөхцөлд гомдлын процесс байгаа боловч одоогоор тусгай public copyright report form эсвэл ил харагдах dedicated холбоо барих хаяг кодоос баталгаажаагүй.

### Одоогоор өөрчлөхгүй үлдээсэн зүйл

AniList API-г бүхэлд нь шууд салгаагүй. Энэ нь анимэ/манганы одоогийн каталог, хайлтын ажиллагааг тасалж болзошгүй бөгөөд API ашиглалт зөвшөөрөгдөх эсэхийг зөвхөн кодоос тогтоох боломжгүй. AniList-ийн бичгээр өгсөн хариу хүртэл арилжааны хэрэглээ болон API нөхцөлийн нийцлийг нээлттэй өндөр эрсдэл гэж үзнэ. Хариу ирээгүй үед хамгийн болгоомжтой сонголт нь AniList-аас хамаарах каталогиудыг түр унтраах юм.

### CMS болон медиа сангийн үлдсэн техникийн шаардлага

- `archive_franchises.cover_image_url`, `archive_works.cover_image_url`, нийтлэлийн body image URL болон Supabase Storage объект бүрд эрхийн бүртгэл холбох.
- Шинэ зураг upload хийхэд `license_type`, `rights_holder`, `source_url`, `permission_reference`, `reviewed_by`, `reviewed_at` заавал шаардах эсвэл `rights_status=unknown` бол нийтлэхийг хориглох.
- Зөвхөн URL талбар биш, Storage bucket дахь бодит объектуудыг inventory болгож, лицензийн баримттай тулгах.
- Нийтийн copyright notice маягт, гомдлын case ID, материал түр нуух, хариу өгөх, counter-notice/давж заалдах дотоод ажиллагааг хэрэгжүүлэх.

Энэ нэмэлт шалгалт нь Supabase Storage-ийн бүх файл болон бүх хэрэглэгчийн нийтлэлийг бүрэн үзсэн гэсэн үг биш.
